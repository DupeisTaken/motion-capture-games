# Installation profiles

Future shareable profiles describe rig geometry, camera roles, image orientation/crop, display layout, calibration revision, quality checks and play boundary. Keep serial numbers, local paths and device identifiers in ignored `.local/` overrides.

Validate profiles on load. Moving a camera or changing relevant geometry must invalidate or reverify calibration. Use [the installation procedure](../../docs/installation.md); do not invent a usable calibration in a sample file.
