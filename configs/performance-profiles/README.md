# Performance profiles

Future validated profiles specify hardware/software identity, actual capture settings, model hash, inference provider, view count, resource limits, supported joints/games, maximum players and measurement evidence.

Keep performance and geometry separate. Distinguish candidate settings from certified settings; never publish an untested three-player or integrated-graphics claim. See [installation](../../docs/installation.md#installation-and-performance-profiles) and [testing](../../docs/testing.md#performance-targets).

No hardware tier has been certified and no runnable profile exists yet.
