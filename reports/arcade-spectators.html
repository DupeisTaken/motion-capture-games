Spectator entry across the motion arcade

November 11, 2026

Slap a Mole and Dodgeball already bind each active round to the joined player. The camera setup now explains that spectators may enter while that track stays reliable. The new regression cases exercise the existing rule through real game entry points with synthetic packets.

  • Slap a Mole continued counting down round time while a spectator reached the target. Only the joined player's wrist scored. When that player disappeared, the target hid and the score stayed fixed.
  • Dodgeball completed its countdown and advanced the ball warning and round timer with reordered detections. The collision body stayed bound to the joined player. The game froze when only the spectator remained.
  • Motion Runner's spectator rule is covered by the existing runner tests and the earlier runner PR #44.
  • Virtual Maze uses synthetic position and direction. The two-camera Slap a Mole rehearsal uses pointer or keyboard input with a synthetic background. Their game input has no spectator-count gate. Both viewer suites passed in the combined preview.
