Before

One Ubuntu job

A single job installed both stacks, ran root checks and built the frontend. Documentation checks, build-output checks and package promotion rules were not explicit. No build artifacts were retained.

After

Separate, observable coverage

Repository checks plus TypeScript and Python jobs on Ubuntu, Windows and macOS feed the stable software-checks gate. Frontend artifacts are retained for seven days.

Build the artifacts that exist

The mirror is the current distributable build. Shared TypeScript modules and games are source-only and are checked through their tests and consuming app build. Python vision remains checkout-based; no wheel or native installer is claimed.

pnpm build:packages picks up declared workspace build scripts in dependency order. New independent packages must add output and clean consumer/install tests, artifact retention and owning documentation. Python packaging requires a resource-location design for schemas/manifests; native/offline distribution remains M5 work.
