Issue #20 · PR #22

Before

One Ubuntu job

A single job installed both stacks, ran root checks and built the frontend. Documentation checks, build-output checks and package promotion rules were not explicit. No build artifacts were retained.

After

Separate, observable coverage

Repository checks plus TypeScript and Python jobs on Ubuntu, Windows and macOS feed the stable software-checks gate. Frontend artifacts are retained for seven days.

Build the artifacts that exist

The mirror is the current distributable build. Shared TypeScript modules and games are source-only and are checked through their tests and consuming app build. Python vision remains checkout-based; no wheel or native installer is claimed.

pnpm build:packages picks up declared workspace build scripts in dependency order. New independent packages must add output and clean consumer/install tests, artifact retention and owning documentation. Python packaging requires a resource-location design for schemas/manifests; native/offline distribution remains M5 work.

Actual verification

  • Local Windows: 233 Vitest tests and 96 pytest tests passed; types, lint and formatting passed.
  • Repository checks passed for 49 tracked Markdown/report files. Production build passed for both configured entries (diagnostics and Mole Motion), including emitted asset checks.
  • Local tools: Node 24.16.0, pnpm 11.25.0 and Python 3.12.14. Hosted jobs use the pinned Node 24.21.0 and Python 3.12.16 versions.
  • All eight hosted jobs passed in run 42792548093 (integrated baseline). Latest implementation-run results are recorded below. English report review uses real local HTTP screenshots at 1440 × 1000 and 390 × 844.
  • GitHub inspection: main is not protected and no repository rulesets are configured. This change documents the required gate without changing hosting policy.
  • Production output: 7 files, 217,792 bytes total on the local Windows run; both HTML entry points and referenced local assets verified.
  • Actionlint 1.7.12 and full-change Git whitespace checks passed. The initial hosted run correctly failed its aggregate gate when setup-python lacked the pinned Windows/macOS installers; uv-managed Python resolved provisioning without changing the version or dropping OS coverage.

The new tooling tests exercise broken anchors/files, offline report dependencies, missing entry points/bundles and accidental remote build scripts. Local heavy checks and browser verification run sequentially.

Evidence limits

  • Hosted software results do not certify USB cameras, GPU inference, participant accuracy, identity continuity, physical latency or installation capacity.
  • DOM tests do not replace real-server UI screenshots. No application UI was changed in this work; the report receives desktop/mobile visual review.
  • Documentation checks cover the repository's local-link and static-report conventions, not remote availability or every Markdown dialect.
  • Branch protection and merge-queue configuration are separate hosting settings; their inspected state is recorded with final verification.
