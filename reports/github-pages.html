Play the arcade in a browser

The GitHub Pages build opens Slap a Mole, Dodgeball, Motion Runner, and Virtual Maze in camera-free rehearsal. Relative page and asset URLs keep navigation under the GitHub project path. The hosted build omits live camera setup and operator tools. Local camera play still uses the Python vision service and the seven-entry local build.

GitHub Pages requires a repository admin or maintainer to select GitHub Actions as the publishing source. The workflow builds pull requests for verification and publishes from main once Pages is enabled. The public deployment is pending. Issue #76 · Pull request #77

Verification

  • pnpm check passed repository and contract checks, 932 TypeScript tests, 314 Python tests, types, lint, formatting, and byte compilation.
  • pnpm build verified seven local entry points. pnpm build:pages verified five static entry points. The hosted Runner JavaScript bundle measured 554.52 kB minified and 148.27 kB gzipped. Vite reported its existing large-chunk advisory.
  • pnpm verify:pages started four rounds at 1440 × 1000 and four at 390 × 844 under /motion-capture-games/. All eight returned to the directory. No vision API calls, WebSocket connections, browser exceptions, or failed assets were observed.
  • pnpm verify:directory --production passed all six destination and return paths, including the local operator tools. The directory passed keyboard navigation and layout at 1440, 390, and 320 pixels wide, plus game navigation with JavaScript disabled.

Chromium used a local static server for the Pages build. Motion Runner requires WebGL 2. Browser verification used only synthetic inputs and did not exercise camera hardware.
