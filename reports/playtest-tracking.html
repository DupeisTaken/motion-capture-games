What changed and why

MediaPipe now derives person bounds from body landmarks. Optional face and finger evidence cannot admit a face-only body or shift its bounds during a turn. Out-of-frame body coordinates remain explicit; anatomical left/right and low-quality joint states are preserved. RTMPose’s detector/pose artifacts and thresholds are unchanged.

The shared session adds opt-in bounded recovery with a constant-size non-biometric token. Existing consumers retain their current behavior by default. Runner and multiplayer campaign PRs own viewer integration; this change edits no game, renderer, enrollment, maze or navigation flow.

Continuity, wrong identity and suspension

Each deterministic scenario has three warmup frames and 12 evaluated 33 ms intervals (396 ms). The target is the original player ID; spectator labels are withheld from the tracker. Detection order alternates. Both association modes are evaluated separately.

Coverage includes missing, tentative, ambiguous and new-ID time in its denominator. A tracker frozen indefinitely scores 0% continuity. Wrong association means a confident ID is attached to a different reference subject, including a spectator; new IDs lose continuity without automatically being labelled wrong. Durations describe labelled observations, not sub-frame or physical timing.

Genuine overlap deliberately remains unresolved: retired IDs never resume the old slot. The dataset is a regression suite, not held-out field evidence. Machine-readable aggregates are in reports/playtest-tracking-results.json.

The recovery contract

const session = new SinglePlayerSession({ recoveryWindowMs: 450 });
// Frame loop, including while no packets arrive:
session.expire(performance.now());
// Observation callback:
const frame = session.ingest(observation, receivedAtMs);
// null + binding: suspend affected scoring; retain the slot.
// null binding: explicit rejoin / new round.
// recovered: break old gesture trails; run recovery countdown.
  • The default window is 0, preserving existing API behavior. The fixed maximum 450 ms is provisional and inherited from tracker retention.
  • Missing, tentative, stale and spectator-only samples never refresh the deadline. Expiry clears memory on ingest or frame-loop polling. Release/new round, source, epoch, geometry, model, tracker and calibration changes flush it.
  • Duplicate incumbent IDs or explicit same-ID ambiguous evidence invalidate immediately, even with stale coordinates. A null-ID ambiguous observation can only suspend; a retired/new ID cannot reclaim the slot.
  • Scores remain game-owned and pinned to the existing slot. Recovery returns only current observed joints and a signal to break pre-gap gesture history.

Memory stores no images, clothing signature, facial feature, body measurement or joint snapshot. Reliable current torso/body geometry can support the existing track through a sparse turn; historical body shape or similar clothing cannot prove a new ID is the same player.

What still needs physical evidence

Side/back-facing pose accuracy, invisible joints, complete occlusion and an indistinguishable replacement remain unmeasured. Neither synthetic box continuity nor a token proves personal identity. New-ID recovery remains explicit. Provider capacity/ranking can still exclude the incumbent before tracking; this repair does not reserve detector capacity.

A local held-out route accepts bounded, labelled normalized observations under ignored .local/ or datasets/ and writes aggregate-only results to ignored paths. It measures coverage, wrong-ID events, ambiguous time, recovery spans and unresolved cases. It does not annotate footage or perform inference. Development clips and untouched participant/session/clothing/lighting-separated clips are needed before threshold changes, model comparisons or training.

Use a second camera first to measure complementary visibility. Cross-view identity and joint fusion still need justified calibration, source timing, correspondence and disconnect/uncertainty tests. No synchronized or calibrated cross-view result is claimed.
