Motion Runner body-width lanes and start

Camera lanes follow the player’s standing reference. One Start press waits for fresh standing input and begins the countdown.

Issue #73 · Runner design

Camera controls

  • Set standing reference where you want the center lane. Lane centers are one shoulder width apart, with hip width as the fallback when a shoulder is occluded.
  • The mirrored preview and game use the same lane calibration. From the center lane, a shift greater than 60% of a lane width enters a side lane. The return threshold is 40%, so small movement near a boundary keeps the current lane.
  • Start run shows the next step when the camera or standing reference is still needed. It waits for 100 ms of fresh standing evidence and then starts the three-second countdown. The separate shoulder and hip medians absorb small single-landmark fluctuations. Cancel start clears the pending request.

Calibrated guides

The fixture stood at 45% of the mirrored frame. The new lane centers appeared at 27%, 45%, and 63%. A shift of 12 percentage points from center in either direction selected the matching side lane. The previous version reported center for both shifts.
